# Auspify Technologies - Task 2: Library Management System

A full-stack Library Management System built as part of the Auspify Technologies Software Development Internship.

## Tech Stack
- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB (Mongoose)

## Features
- 📖 Book Management (Add, Delete, View)
- 🔄 Issue & Return Books
- 🔍 Search Books
- 📊 Real-time Status (Available / Issued)

## How to Run

### Backend
\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`

### Frontend
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`

### Environment Variables (backend/.env)
\`\`\`env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/auspify_library_db
\`\`\`
